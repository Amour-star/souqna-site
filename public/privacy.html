Privacy Policy – Souqna

Effective Date: January 1, 2026

1. Introduction (Who we are)

Souqna (app package: com.souqnaapp) is a local marketplace app that helps users buy, sell, and communicate securely. This Privacy Policy explains how we collect, use, and protect personal information.

سوقنا (حزمة التطبيق: com.souqnaapp) هو تطبيق سوق محلي يساعد المستخدمين على البيع والشراء والتواصل بشكل آمن. توضح سياسة الخصوصية هذه كيفية جمع المعلومات الشخصية واستخدامها وحمايتها.

2. Data We Collect

  • Name / الاسم
  • Email / البريد الإلكتروني
  • Phone / رقم الهاتف
  • Profile information / معلومات الملف الشخصي
  • Listings content / محتوى الإعلانات
  • Photos / الصور
  • In-app messages / الرسائل داخل التطبيق
  • Precise location (GPS, permission-based) / الموقع الدقيق (GPS بعد منح الإذن)
  • Device identifiers (Firebase token, installation ID) / معرّفات الجهاز (رمز Firebase، ومعرّف التثبيت)

3. How We Use Data

  • Account management / إدارة الحساب
  • Marketplace functionality / تشغيل وظائف السوق
  • Messaging between users / المراسلة بين المستخدمين
  • Security and fraud prevention / الأمان ومنع الاحتيال
  • Service improvement / تحسين الخدمة

4. Data Sharing

  • Between users through listings and chat / بين المستخدمين عبر الإعلانات والمحادثات
  • With Firebase services (Auth, Firestore, Messaging) / مع خدمات Firebase (المصادقة، Firestore، الرسائل)
  • With hosting providers / مع مزودي الاستضافة
  • When required by legal obligations / عند وجود التزام قانوني

We do NOT sell personal data.

نحن لا نبيع البيانات الشخصية.

5. Security

All data is transmitted over HTTPS using TLS encryption.

يتم نقل جميع البيانات عبر HTTPS باستخدام تشفير TLS.

6. Data Retention

We retain data only as long as necessary for account operation, safety, legal compliance, and dispute resolution.

نحتفظ بالبيانات فقط للمدة اللازمة لتشغيل الحساب، والسلامة، والامتثال القانوني، وحل النزاعات.

7. User Rights

You can request access to your data, correction of inaccurate data, and deletion of your account and personal data.

يمكنك طلب الوصول إلى بياناتك، وتصحيح البيانات غير الدقيقة، وحذف حسابك وبياناتك الشخصية.

8. Contact

For privacy and data requests, contact: support@souqna.net

لطلبات الخصوصية والبيانات، تواصل عبر: support@souqna.net
